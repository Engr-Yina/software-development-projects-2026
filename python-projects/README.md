# Python Projects Collection 🐍

A collection of beginner-friendly, terminal-based Python applications developed to strengthen my programming skills, problem-solving ability, and understanding of software development fundamentals.

This directory is part of my **Software Development Projects 2026** repository, where I organize and document practical projects built throughout my software development learning journey.

## 📌 About This Collection

These projects focus on solving practical, real-world problems using Python. Each application runs in the terminal and uses text-based menus, user input, and program output to interact with users.

The projects provide hands-on practice with Python fundamentals, functions, conditional statements, loops, data structures, input validation, and application logic.

**Note:** These are command-line applications. They do not currently include graphical user interfaces (GUIs) or web-based interfaces.

## 📂 Projects

| Project | Description |
|---|---|
| **To-Do App** | A simple task management application for adding, viewing, and managing tasks. |
| **Age Calculator** | Calculates a person's age using their date of birth. |
| **Banking App** | Simulates basic banking operations such as checking balances and performing transactions. |
| **Password Generator** | Generates passwords using configurable character combinations. |
| **Inventory Management System** | Helps manage product records, stock quantities, and inventory operations. |
| **Attendance Management System** | Records and manages attendance information. |
| **Mini School Management System** | Simulates basic school administration and record management. |

*The features listed above describe the intended purpose of each project. Refer to the individual project files for the functionality currently implemented.*

## ⚙️ Requirements

To run these projects, you need:

- Python 3 installed on your computer.
- A terminal or command prompt.
- A code editor such as Visual Studio Code (optional).

Check your Python installation with:

```bash
python --version
```

On some systems, you may need to use:

```bash
python3 --version
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Engr-Yina/software-development-projects-2026.git
```

### 2. Navigate to the Python projects directory

```bash
cd software-development-projects-2026/python
```

### 3. Open a project folder

For example:

```bash
cd to-do-app
```

Replace `to-do-app` with the name of the project you want to run.

### 4. Run the Python application

If the main Python file is named `main.py`, run:

```bash
python main.py
```

If your project uses a different filename, replace `main.py` with the correct filename. On systems using `python3`, run `python3 main.py` instead.

**Tip:** Check each project's files or README for its specific setup and execution instructions.
